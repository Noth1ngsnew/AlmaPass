# AlmaPass — frontend

Angular-приложение: каталог событий, страница события, вход, избранное, профиль. Языки: EN, RU, KZ.

```bash
npm install
npm start        # http://localhost:4200
```

Бэкенд должен быть запущен на http://127.0.0.1:8000 (адрес задаётся в `src/app/core/config.ts`).

Переводы интерфейса лежат в `src/app/core/translations.ts`.
